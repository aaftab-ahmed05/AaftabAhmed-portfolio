## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/aaftab-ahmed05/AaftabAhmed-portfolio.git
```

### 2. Navigate to the project

```bash
cd AaftabAhmed-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```
